# استاندارد طراحی: رنگ‌ها و چیدمان

همه صفحه‌ها از **یک** مجموعه رنگ معنایی استفاده می‌کنند که در `web/src/styles/tokens.css` تعریف شده است. هر رنگ یک معنی دارد و همان معنی در همه صفحه‌ها یکی است؛ رنگ هگز مستقیم در صفحه‌ها نوشته نمی‌شود.

## رنگ‌های معنایی

| توکن | رنگ | معنی | نمونه |
| :--- | :--- | :--- | :--- |
| `--color-primary` | آبی | اقدام اصلی، تب فعال، فوکوس، لینک و نکته اطلاعاتی | دکمه «ثبت …»، قسط بعدی |
| `--color-positive` | سبز | پول ورودی، سود، پرداخت‌شده / وصول‌شده / انجام‌شده | درآمد، خرید، قسط پرداخت‌شده |
| `--color-negative` | قرمز | زیان، معوق، خطا و کار حذف‌کردنی | زیان، قسط معوق، فروش، حذف |
| `--color-warning` | کهربایی / طلایی | بدهی باقیمانده، سررسید نزدیک، توجه — و رنگ برند برای عدد اصلی هر صفحه | مانده بدهی، ارزش کل پورتفو |

هر رنگ چهار سایه دارد:

- پایه (`--color-*`): پس‌زمینه، آیکون و border.
- `-text`: متن روی سطح تیره.
- `-soft`: پس‌زمینه کم‌رنگ برای badge، chip و alert.
- `-border`: حاشیه‌ی همان‌ها.

برای متن از کلاس‌های `.text-positive`، `.text-negative`، `.text-warning` و `.text-accent` استفاده می‌شود.

**بقیه چیزها خنثی‌اند:** مبالغی که نه ورودی‌اند و نه خروجی، برچسب‌ها و توضیحات از `--text-primary`، `--text-secondary` و `--text-muted` استفاده می‌کنند.

**رنگ‌های دسته‌ای** (نمودارها، دسته دارایی‌ها و منابع درآمد) فقط از پالت `web/src/shared/ui/chartColors.js` می‌آیند و معنای بالا را ندارند. کارشان فقط تشخیص یک دسته از دیگری است.

## ظاهر: مینیمال و تخت

- **سایه و درخشش نداریم:** نه `box-shadow` بیرونی، نه glow رنگی، نه `text-shadow` و نه `drop-shadow`. سطح‌ها با border از هم جدا می‌شوند. توکن‌های سایه (`--card-shadow`، `--primary-glow`، `--shadow-*`) مقدار `none` دارند.
- **کارت داخل کارت:** کارتی که داخل کارت دیگری است (مثل هر وام داخل گروه بانکش) با `--card-inner-bg` و `--card-inner-border` یک پله روشن‌تر از کارت بیرونی است تا لایه‌ها بدون سایه از هم جدا شوند. هاور آن فقط کمی روشن‌تر شدن پس‌زمینه و border است.
- **کارت ردیفی:** رکوردی که در طول زمان جلو می‌رود (وام، اشتراک) یک ردیف تمام‌عرض است، `RowCard` (`shared/ui/RowCard.jsx`، `styles/row-card.css`): آیکن، عنوان، یک خط زیرش و یک نشان (`RowCardBadge`)؛ بعد ستون‌های عدد (`RowCardBlock`) که یکی نوار پیشرفتِ کشسان است (`RowCardProgress`)؛ بعد دکمه‌های آیکنی (`RowCardAction`، بقیه در منوی «⋮» `ActionMenu`). رنگ‌ها همان رنگ‌های معنایی‌اند (`warning`، `positive`، `negative`، `primary`، `muted`). فهرست تازه‌ای از چنین رکوردهایی از همین استفاده می‌کند، نه کارت جداگانه.
- **استثنا:** `box-shadow` فقط برای حلقه‌هایی که نقش border دارند (`inset 0 0 0 1px` یا `0 0 0 Npx`) و حلقه‌ی فوکوس فرم‌ها به کار می‌رود.
- **گرادیان نداریم:** دکمه‌ها و اعداد تک‌رنگ‌اند. `--primary-gradient` و `--gold-gradient` هر دو یک رنگ ثابت‌اند؛ برای همین عدد اصلی صفحه و بقیه‌ی مقادیر طلایی دقیقاً هم‌رنگ‌اند.

## چیدمان

- **دکمه اصلی هر صفحه** (ثبت / افزودن) همیشه کامپوننت مشترک `Button` است و رنگ آبی دارد، هم در سربرگ صفحه و هم در حالت خالی.
- **ابزارهای هر نما** در پورتفو (جستجو، خروجی و ورودی و تنظیمات دارایی‌ها؛ بازه زمانی تراکنش‌ها) در همان ردیف تب‌های «دارایی‌ها / تراکنش‌ها» قرار می‌گیرند.
- **کارت دور لیست:** لیستی که خودش از کارت ساخته شده (گروه‌های بانک در وام‌ها، گروه‌های دارایی در پورتفو) داخل کارت دیگری قرار نمی‌گیرد. برای این حالت از `portfolio-table-card is-plain` استفاده می‌شود که شفاف است و padding ندارد. جدول ساده (درآمدها، تراکنش‌ها، چک‌ها) داخل کارت می‌ماند.
- **هشدارهای سررسید** فقط جایی نمایش داده می‌شوند که به آن مربوط‌اند:
  - اقساط معوق: در خانه و صفحه وام‌ها.
  - چک‌ها: در خانه.

  وضعیت به‌روزرسانی قیمت‌ها هم فقط در خانه و پورتفو می‌آید.
- **منتظر سرور:** نوشتنی که در راه است (`FullscreenLoader`) و تبی که تازه باز شده و هنوز منتظر داده‌اش است (`TabLoadingGate`) هر دو همان `BlockingOverlay` را نشان می‌دهند (`shared/ui/BlockingOverlay.jsx`، `styles/loading.css`): لودری وسط صفحه که هر لمس، کلید و اسکرول را می‌گیرد تا چیزی پشت آن باز یا دوباره فرستاده نشود. لودر تب فقط وقتی داده‌اش بیش از ۳۰۰ میلی‌ثانیه طول بکشد دیده می‌شود؛ خواندنی که ۲۰ ثانیه پاسخ نگیرد رها می‌شود (`READ_TIMEOUT_MS`) و قفل باز می‌شود.
- **در اپ اندروید** (`styles/app-shell.css`): پنجره‌ها به‌صورت bottom sheet باز می‌شوند و با کشیدن به پایین بسته می‌شوند، دکمه‌های پایین فرم هم‌اندازه‌اند، و در گوشی فهرست‌ها پیش از کارت‌های خلاصه و نمودارها می‌آیند.
